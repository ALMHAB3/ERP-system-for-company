# Glossary of terms / قاموس المصطلحات

المصطلحات المستخدمة في الشاشات، مع مقابلها الإنجليزي وتعريف مختصر. واجهة النظام تعمل بالعربية أو الإنجليزية (زر اللغة في القائمة الجانبية).

| العربية | English | المعنى |
|---|---|---|
| الصنف | Item / SKU | منتج له رمز فريد |
| الدفعة (التشغيلة) | Lot / batch | كمية وصلت معاً (شحنة أو دفعة مورد) لها تكلفة وتاريخ صلاحية خاصان |
| المخزون الفعلي | On hand | الموجود فعلاً في المستودع |
| المحجوز | Reserved | محجوز لطلبات بيع لم تُسلَّم بعد |
| المتاح للبيع | Available to sell (ATP) | الفعلي − المحجوز |
| الشحنة | Shipment (inbound consignment) | بضاعة مستوردة قادمة من مورد (حاوية/بوليصة) |
| تسليم الطلب | Deliver an order | صرف بضاعة طلب بيع من المخزون إلى العميل |
| التكلفة الفعلية | Landed cost | سعر الشراء + الشحن + التأمين + الجمارك + التخليص، موزَّعة على الأصناف |
| القيمة الجمركية (CIF) | Customs value | سعر البضاعة + الشحن + التأمين؛ أساس الرسم الجمركي |
| الرسم الجمركي % | Customs duty % | نسبة الرسم حسب بند التعرفة لكل صنف |
| تكلفة البضاعة المباعة | Cost of goods sold (COGS) | تكلفة الدفعة التي خرجت فعلاً في البيع |
| التكلفة التقديرية / النهائية | Estimated / final cost | التقديرية عند الاستلام؛ النهائية بعد سداد الشحنة بأسعار الصرف الفعلية |
| سعر الصرف | Exchange rate | كم دينار ليبي (LYD) تساوي وحدة من العملة الأجنبية |
| فرق العملة | Exchange difference | فرق بين سعر صرف الفاتورة وسعر صرف الدفع |
| المستلم غير المفوتر (GR/IR) | Goods received not invoiced | قيمة بضاعة استُلمت ولم تصل فاتورتها بعد |
| فروق أسعار الشراء | Purchase price variance | فرق بين المستلم والمفوتر بعد إغلاق الشحنة |
| ذمم العملاء (المدينون) | Accounts receivable | ما يستحقه علينا العملاء |
| ذمم الموردين (الدائنون) | Accounts payable | ما نستحقه للموردين |
| أعمار الديون | Debt ageing | تصنيف الديون حسب أيام التأخر عن الاستحقاق |
| البيع نقداً | Cash sale | يُدفع عند البيع ويدخل الصندوق |
| البيع بتحويل مصرفي | Bank-transfer sale | يُدفع عند البيع ويدخل المصرف المختار |
| البيع بالأجل (الآجل) | Credit sale | يُدفع لاحقاً؛ لا يتم إلا لعميل مسجَّل لدى الشركة |
| العميل النقدي | Cash (walk-in) customer | عميل غير مسجَّل للبيع نقداً أو بالتحويل فقط |
| حد الائتمان | Credit limit | أقصى مديونية مسموحة للعميل المسجَّل (0 = بلا حد) |
| إشعار دائن | Credit note | مستند يخفض الفاتورة عند إرجاع بضاعة |
| الصندوق | Cash till | حساب النقد بالمقر |
| الحساب المصرفي | Bank account | لكل مصرف حساب مستقل في الأستاذ |
| ميزان المراجعة | Trial balance | أرصدة كل الحسابات؛ مجموع المدين = مجموع الدائن |
| القيد العكسي | Reversing entry | طريقة تصحيح القيود (لا تُعدَّل بل تُعكس) |
| نقطة إعادة الطلب | Reorder point | الرصيد الذي يستوجب الشراء: الطلب خلال مدة التوريد + مخزون الأمان |
| مخزون الأمان | Safety stock | احتياطي لتقلب الطلب (مستوى خدمة 95%) |
| مدة التوريد | Lead time | الأيام من الطلب إلى وصول البضاعة |
| دوران المخزون | Inventory turnover | تكلفة المباع السنوية ÷ قيمة المخزون |
| الهامش % | Margin % | (السعر − التكلفة) ÷ السعر في التقارير؛ نسبة الربح على التكلفة في اقتراح الأسعار |
| WAPE | Weighted absolute percentage error | خطأ التنبؤ على آخر 3 أشهر (الأقل أفضل) |
| سجل التدقيق | Audit log | سجل غير قابل للتعديل لكل عملية حساسة |

ملاحظة: «الهامش %» في التقارير = الربح ÷ الإيراد، بينما «نسبة الربح %» في اقتراح الأسعار = الربح ÷ التكلفة.
